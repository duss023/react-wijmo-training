按“讲解 → 代码 → 画面”授课

全课程共 18 课。不要一次讲完多个控件；先让学员理解当前问题，再去源码和页面验证。

每课固定 15～25 分钟

  1. 3～5 分钟：读本课问题和通俗讲解。请学员用自己的话复述。
  2. 5～8 分钟：逐段查看代码。利用“代码怎样对应到画面”表，指出每个参数的页面效果。
  3. 5～8 分钟：打开对应模块，按照步骤操作，并核对“应该看到”。
  4. 2～4 分钟：让学员完成小练习，再展开参考答案。

建议分两天

第一天：01～11 课，认识 React 状态、业务数据、网格与表单。第二天：12～14 课，理解事件、图表和五层树；15～18 课选学分析、异步、保存和导出，剩余时间进行综合练习。

需要记住的界限

  • 第 1 课先讲整体代码结构和状态更新的 5 个步骤。各画面在 pages 目录独立管理；代码片段从真实源码自动提取，并带行号，上下文可通过“打开完整源码”查看。
  • 截图是模块示例画面，不表示每一个操作后的状态。实际操作后以“应该看到”文字验收。
  • 若画面被截断，向下或横向滚动；点击截图可以放大。
  • Demo 通过真实 fetch 连接本地模拟 API，不连接公司后台。GET 读取、PUT 保存、DELETE 重置；数据仅在本地服务内存中保留，重启后恢复初始。npm run preview 同样提供 API，普通静态托管不提供 API。输入校验不能代替后台权限。
  • Wijmo 为商业组件，正式使用需授权。PDF 中文字体须单独配置。
