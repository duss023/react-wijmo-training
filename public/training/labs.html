实验 5 · 异步与故障恢复

任务：保存一条更改，然后启用接口故障，再关闭并重载。解释 AbortController 的职责。

验收：故障提示可见；重试恢复已保存记录；取消请求不显示错误。

提示：Effect 返回 controller.abort；catch 过滤 AbortError。

参考答案与讲评 
loadProjects 通过 fetch 请求本地 GET /api/projects，response.ok 检查 HTTP 状态，response.json() 解析响应，response.data 进入 view。保存发送 PUT，重置发送 DELETE。fetch 使用同一个 AbortSignal，取消或普通 HTTP 500 走不同错误处理路径。

课程自测（含答案）

  1. clearChanges 能否撤销对象修改？
    答案 不能，它清除变更跟踪标记。
  2. 虚拟滚动是否减少接口传输量？
    答案 不直接减少，它主要减少渲染的行与 DOM。
  3. JSON 保存日期后为什么会出错？
    答案 Date 会变成字符串，恢复时应转换并校验。
  4. 前台下拉限制是否等同于权限？
    答案 不是。后台需校验权限和输入，不能相信浏览器。
  5. 为什么不在每次 render 时创建 CollectionView？
    答案 会重置视图、当前项和事件关系；稳定实例更易保持状态并正确清理。
